# NexBuy – E-Commerce Store

A responsive e-commerce web application built using plain HTML, CSS, and JavaScript, designed to showcase products, manage a shopping cart, and simulate a user’s shopping experience on a modern online store.

# Features

- Responsive product listing pages

- Product details view (name, price, description)

- Add to cart functionality

- Cart page with item quantity update and total price calculation

- Navigation bar with categories or sections

# Purpose & Goals

- Provide a clean, user-friendly shopping interface

- Demonstrate front-end skills in building a functional, interactive e-commerce UI

- Serve as a portfolio project to show ability to implement shopping cart logic without a framework

- Simulate a real-world online store experience for demonstration / learning
